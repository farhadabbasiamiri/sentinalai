## Repository operating guide

- Keep the project deterministic, synthetic, and defensive.
- Do not introduce live credentials, cloud access, or real enterprise data.
- The backend is the source of truth for scoring and governance evaluation.
- Prefer small, reviewable changes with clear tests.
- Update README and docs whenever major behavior changes occur.
- Before finishing, run the relevant tests and confirm the project still builds.
- Keep the final demo focused on evidence, approvals, and explainability.
